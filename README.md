# Ghostty, with Vertical Tabs

A fork of Ghostty for macOS that adds:

- **Vertical tabs.** Every tab in a sidebar. Drag to reorder, archive what you're not using.
- **⌘K search.** Find any tab by its title or by what's in the terminal.
- **Last Messaged sort.** The tab you last sent a message in comes first.

## Download

**[Download for Mac](https://github.com/MusaAqeel/ghostty/releases/latest/download/Ghostty.zip)** (Apple Silicon)

Unzip, drag Ghostty to Applications, then run this once since the app isn't notarized:

```sh
xattr -dr com.apple.quarantine /Applications/Ghostty.app
```

It uses your existing Ghostty config.
